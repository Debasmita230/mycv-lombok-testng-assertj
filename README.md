1) My CV Automation Project (Lombok + TestNG + AssertJ):-

This project creates and validates a formatted CV using Lombok models, TestNG annotations, and AssertJ assertion.

2)  Features:-
- Uses `@BeforeClass`, `@Test`, and `@AfterClass` for setup, execution, and validation  
- Prints a beautified CV output to the console  
- Asserts all required fields are present  

3)  How to Run:-
Clone the repo, open in Eclipse as a Maven project, and run  
`CvTest.java` as a TestNG Test.
